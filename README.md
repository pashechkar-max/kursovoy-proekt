# ✈️ Aether Airways — Курсовой проект

> **Веб-сервис флагманской авиакомпании Aether Airways**  
> Полнофункциональная информационная система бронирования авиабилетов, управления тарифами, перевозки животных и программы лояльности пассажиров.

---

## 📌 О проекте

Проект разработан в рамках курсовой работы. Реализует полный цикл взаимодействия пассажира и авиакомпании: от поиска рейсов и выбора мест в салоне самолёта до оформления багажа, перевозки домашних животных, управления милями и генерации официальных маршрутных квитанций в формате PDF.

---

## 🚀 Основной функционал

1. **Поиск и фильтрация рейсов**:
   - Поиск по городам вылета и прилёта, датам и времени суток.
   - Сортировка по цене (возрастание / убывание).
   - Фильтрация рейсов с доступными квотами для путешествий с питомцами.
2. **Интерактивная карта салона лайнера (Airbus A320)**:
   - Выбор конкретного кресла в салоне (Бизнес, Комфорт, Эконом).
   - Блокировка мест, занятых активными бронями в реальном времени.
   - Учёт авиационных зон безопасности (аварийные выходы, места у иллюминатора).
3. **Бронирование с фиксацией тарифа на 24 часа**:
   - Гарантированное сохранение стоимости билета на сутки.
   - Продление срока действия брони на дополнительные 24 часа за бонусные мили (500 миль).
   - Возможность добровольной отмены бронирования с моментальным освобождением места.
4. **Услуга перевозки домашних животных (Flights with Pets)**:
   - В салоне под креслом (до 8 кг, IATA PETC).
   - На отдельном пассажирском кресле у окна (до 15 кг, IATA EUPS).
   - В отапливаемом багажном отсеке (до 50 кг, IATA AVIH).
   - Бесплатный провоз собак-поводырей (IATA SVAN).
   - Строгий контроль квот на рейс и проверка ветеринарных данных.
5. **Программа лояльности AetherMiles**:
   - Приветственный бонус 1 000 Welcome Miles при регистрации.
   - Начисление 20% от стоимости перелёта после завершения рейса.
   - Апгрейд класса обслуживания (Эконом → Комфорт) за 2 000 миль.
   - Детализированная история транзакций по счёту.
6. **Официальные маршрутные квитанции (PDF)**:
   - Автоматическая векторная генерация электронного билета (DomPDF).
   - Блоки пассажира, маршрута, класса, штрих-кода и спецкодов перевозки животных.
7. **Панель администратора**:
   - Управление статусами рейсов (Scheduled, Delayed, Cancelled, Completed).
   - Автоматическое начисление миль пассажирам при переводе рейса в статус «Завершён».
8. **Безопасность и отказоустойчивость**:
   - Защита от перебора паролей и спам-регистраций (Rate Limiting).
   - Многоуровневая валидация паспортных данных РФ.
   - Ролевая модель доступа (Middleware: Гость, Пассажир, Администратор).

## 🛠 Технологический стек

- **Бэкенд**: PHP 8.2+, Laravel 11 (Eloquent ORM, Blade, Service Providers, Middleware)
- **База данных**: MySQL / MariaDB (InnoDB, Foreign Keys, Transactions)
- **Фронтенд**: HTML5, CSS3 (модульная архитектура в `public/style/`), JavaScript (ES6, Fetch API)
- **PDF-генерация**: Barryvdh DomPDF
- **Тестирование**: PHPUnit 12 (100% покрытие ключевых сценариев: 25 тестов, 93 проверки)

## ⚙️ Установка и запуск

1. **Клонирование репозитория**:
   ```bash
   git clone https://github.com/pashechkar-max/kursovoy-proekt.git
   cd kursovoy-proekt
   ```

2. **Установка зависимостей Composer**:
   ```bash
   composer install
   ```

3. **Настройка окружения**:
   ```bash
   copy .env.example .env
   php artisan key:generate
   ```
   *Укажите параметры подключения к вашей базе данных MySQL в файле `.env`.*

4. **Запуск миграций и сидирование тестовых данных**:
   ```bash
   php artisan migrate:fresh --seed
   ```

5. **Запуск локального веб-сервера**:
   ```bash
   php artisan serve
   ```
   *Приложение будет доступно по адресу: `http://localhost:8000`*

6. **Запуск тестов**:
   ```bash
   php artisan test
   ```
